## 📦 Open Source: ToastifyX

<div align="center">

<a href="https://www.npmjs.com/package/toastifyx"><img src="https://img.shields.io/npm/v/toastifyx?style=for-the-badge&logo=npm&color=CB3837&label=npm" alt="npm version" /></a>
<a href="https://www.npmjs.com/package/toastifyx"><img src="https://img.shields.io/npm/dt/toastifyx?style=for-the-badge&logo=npm&color=CB3837&label=downloads" alt="npm downloads" /></a>
<a href="https://github.com/sumitgangwar127/ToastifyX"><img src="https://img.shields.io/badge/dependencies-0-2ea44f?style=for-the-badge" alt="zero dependencies" /></a>
<a href="https://github.com/sumitgangwar127/ToastifyX"><img src="https://img.shields.io/npm/l/toastifyx?style=for-the-badge&color=2c5364" alt="license" /></a>

</div>

A lightweight, animated, **zero-dependency** toast notification library that works with any framework, or none. Designed around a flexible, config-driven API with a focus on developer experience and performance.

```bash
npm install toastifyx
```

```js
import ToastifyX from "toastifyx";
import "toastifyx/dist/toastifyx.css";

ToastifyX.success("Saved successfully!");

ToastifyX.show({
  type: "info",
  message: "New update available",
  position: "top-right",
  animation: "pop",
  duration: 3000,
});
```
